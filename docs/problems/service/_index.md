This section documents canonical service-level problem pages used by operators and diagnostics tooling.

Available service problem leaves:

- unsupported — service is not supported on this platform or configuration
- busy — temporary overload condition; queueing and throttling recommended
- timeout — request/operation exceeded configured deadline or hung

Create leaf pages in this directory to document remediation steps and monitoring guidance for each problem type.
